# AI Engineering Journey

Start date: 2026-10-26

## Repo layout

- `weeks/` – one folder per week, starting with the foundations.
- `projects/` – portfolio capstones and app projects.
- `scripts/` – verification and environment checks.
- `flagship_chat_assistant/` – the final flagship app prototype and deployment example.

## Safety and honesty

- Keep API keys in `.env` only.
- Do not commit secrets.
- If a tool or service cannot be run here, mark it `UNVERIFIED`.
- The Docker example is included as a learning scaffold; it was not run in this environment unless explicitly validated.
