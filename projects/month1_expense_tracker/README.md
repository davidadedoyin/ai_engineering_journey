# Expense Tracker

This is a beginner-friendly command-line expense tracker. It lets you add expenses, categorise them, save them to a JSON file, and show totals.

## How to run

```bash
python expense_tracker.py
```

## Example commands

1. Add an expense
2. View totals
3. Show categories
4. Exit

## Limitations

This is a simple learning project. It is not connected to a database or a real payment system.
