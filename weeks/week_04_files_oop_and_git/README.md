# Week 04: Files, OOP and Git

## Analogy

A class is a blueprint. An object is the actual thing made from that blueprint. A Git commit is a checkpoint in your project history.

## Topics

- reading and writing files
- a basic `Contact` class
- debugging tracebacks
- git add, commit and status

- I can save data to a file.
