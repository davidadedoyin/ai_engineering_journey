# Week 11 reflection

## prompts

- What is a classifier trying to do?
- Why is logistic regression called a probability model?
- What is a decision tree in simple terms?
- How can a tree become overfit if the max depth is too high?
- Which classifier felt easier to understand?

## example answer

A classifier tries to map input information to a label such as spam or not spam. Logistic regression gives the probability that an example belongs to each class before choosing the most likely one. A decision tree is like a flowchart where each question splits the data into smaller groups. A tree can become overfit when it gets too deep and starts memorizing tiny details rather than learning the broad pattern. I found the decision tree easiest to understand because it feels like asking yes/no questions.
