# Week 09: What is machine learning?

## Analogy

Machine learning is like teaching a student by showing lots of examples. The student learns patterns, then tries to make predictions on new examples.

## Mon: supervised vs unsupervised learning

Supervised learning uses labeled examples. That means each example comes with a known answer.

Example:
- Input: house size
- Output: house price

Unsupervised learning finds structure in data without labels.

Example:
- group customers by similar buying habits

## Tue: regression vs classification

Regression predicts a number.

Example:
- predict the price of a house

Classification predicts a category.

Example:
- predict whether a person survived or not

## Wed: the ML workflow

The workflow is:
1. collect data
2. clean and prepare it
3. split into train and test sets
4. train a model
5. evaluate the model
6. improve the model and repeat

This is written in plain language: we learn from past examples, then test on new examples.

## Thu: overfitting vs underfitting

Overfitting means the model memorizes the training data too closely and does poorly on new data.

Underfitting means the model is too simple and does not learn enough.
