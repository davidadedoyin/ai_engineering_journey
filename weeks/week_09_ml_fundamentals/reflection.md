# Week 9 reflection

## prompts

- What is the difference between supervised and unsupervised learning?
- Why do we split data into train and test sets?
- What is overfitting in plain English?
- Why is the ML workflow iterative?
- Which part of machine learning feels most intuitive to you so far?

## example answer

Supervised learning uses labeled examples, while unsupervised learning finds patterns without labels. We split data into train and test sets so we can learn on one portion and check the model on an unseen portion. Overfitting happens when the model memorizes training examples instead of learning the general pattern. The workflow is iterative because we often train, evaluate, adjust and repeat until the model is good enough. The most intuitive part for me was seeing that a model learns patterns from data instead of being hand-coded for every possible case.
