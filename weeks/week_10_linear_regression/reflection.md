# Week 10 reflection

## prompts

- What problem does a regression model solve?
- What does the slope of the line mean in plain English?
- Why do we need more than one metric when we evaluate a model?
- Why can an extra useful feature improve predictions?
- Which part of this week felt most concrete?

## example answer

A regression model solves problems where the output is a number, such as price or time. The slope tells us how much the target changes when the input changes. We need multiple metrics because MAE, MSE and R² all describe the error from different angles. A useful extra feature can improve predictions by giving the model more information about the real pattern. The most concrete part for me was seeing a line fit to a few data points and then predicting a new value from it.
