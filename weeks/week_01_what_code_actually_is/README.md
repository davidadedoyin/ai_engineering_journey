# Week 01: What code actually is

## Analogy

Think of code like a recipe. A recipe tells a cook what ingredients to use and what steps to follow. Programs do the same thing: they tell the computer exactly what to do.

## Main idea

A script is a set of instructions. Python reads those instructions one line at a time.

## Mon: Hello, World

We create a simple script that prints a greeting.

```python
print("Hello, world!")
```

## Tue: variables and user input

```python
name = input("What is your name? ")
print(f"Hello, {name}!")
```

## Wed: types and conditionals

```python
age = 19
if age >= 18:
    print("You are an adult.")
else:
    print("You are a minor.")
```

## Thu: functions

```python
def add(a, b):
    return a + b

print(add(2, 3))
```
