# Human tasks

These steps require your account or machine, not just the repo.

1. Install Python, VS Code, and Git.
2. Create a GitHub account and repo named `ai-engineering-journey`.
3. Create a Kaggle account and download Titanic if you want the official dataset.
4. Open the Colab notebooks when the roadmap reaches deep learning and fine-tuning.
5. Create your Anthropic Console account and set a spending limit.
6. Add `ANTHROPIC_API_KEY` and `ANTHROPIC_MODEL` to `.env` before using any LLM endpoint.
7. Publish the GitHub profile README at the end of the journey.
